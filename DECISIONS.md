# Технические решения VELTRIX

| Область | Решение | Практический эффект |
| --- | --- | --- |
| Интерфейс | SwiftUI, SF Pro, SF Symbols, оригинальная V-эмблема, графика SwiftUI Canvas | Своя композиция экранов, карты и графики рисуются нативно. |
| Минимальная версия | iOS 16.0, ARM64 для iPhone, Swift 5 language mode | ChartOverlay и MagnificationGesture доступны на iOS 16. Liquid Glass компилируется с Xcode 26 и включается при доступности iOS 26. |
| Архитектура | MVVM с внедряемыми LedgerStore, MarketDataProvider и HTTPTransport | Модель связывает UI, данные и команды. XCTest проверяет ядро и ошибки транспорта. |
| Хранение | Одна версионированная запись Core Data в SQLite | Балансы, ордера, карты и журнал коммитятся одним сохранением. При ошибке шага данные в интерфейсе не заменяются. |
| Денежные расчёты | Decimal, USD как валюта учёта, проверка результата операций, средневзвешенная себестоимость | Комиссия входит в себестоимость покупки и вычитается из поступления продажи. Распределённая себестоимость частичного списания округляется, остаток остаётся в позиции. |
| Ордера | Лимитный резерв на вводе, полное исполнение по актуальной цене при выполнении условия, UUID команды | Резерв уменьшает доступные средства. Отмена освобождает резерв. Коммиты модели сериализованы главным актором. |
| Переводы и карты | Локальные метки получателя/отправителя, четыре оформления, привязка карты к портфелю, возврат по исходной операции | Интерфейс даёт воспроизвести сценарий без движения средств и без действующих реквизитов. |
| Рынок | CoinGecko REST, Kraken REST/WS, Frankfurter v2 | Источник и дата котировки доступны в интерфейсе. Kraken и CoinGecko могут различаться, так как показывают цены биржи и сводные цены соответственно. |
| История | Портфельные снимки, линии и реальные OHLC для активов, локальный кеш | График портфеля показывает наблюдённую историю. Длинные серии прореживаются для отрисовки. |
| Доступ | LocalAuthentication, PIN PBKDF2-HMAC-SHA256 с солью, ограничение повторов в Keychain | Защита применяется при запуске и после истечения времени блокировки в фоне. |
| Сборка | XcodeGen, стандартный runner macOS GitHub, unsigned IPA после тестов | Подпись выполняется пользователем через Sideloadly или AltStore. |

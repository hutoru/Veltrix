# Аудит VELTRIX 8.1

Ветка `veltrix-7-redesign`, базовая ревизия `74d506c`. Статус «Изменено» означает исправление в рабочей копии. Проверки, требующие Xcode или физического устройства, перечислены ниже.

| Приоритет | Проблема | Причина | Статус |
| --- | --- | --- | --- |
| P0 | Нет заданного фона системного экрана запуска. SwiftUI держит заставку почти секунду | Пустой `UILaunchScreen` и фиксированная задержка | Изменено. Системный storyboard с фоном #080809, логотип VELTRIX и переход за 360 мс в обычном режиме |
| P0 | При возврате из фона состояние блокировки и системный диалог могут пересечься с восстановлением интерфейса | Таймер блокировки пересчитывался только на смене SwiftUI ScenePhase, а состояния были отдельными флагами | Изменено. AuthCoordinator с явными состояниями, досрочный пересчёт на выходе из фона и отклонение результата старого запроса |
| P0 | При первой операции пополнения, перевода или карты iOS мог не предложить разрешение | Запрос разрешения запускался только для покупки, продажи и обмена | Изменено. Запрос разрешения от всех поддерживаемых событий, техническое уведомление в настройках, устранение дубликатов и переход к ценовым оповещениям |
| P0 | Некоторые лимитные ордера не проходили проверку при повторном открытии базы или импорте | Движок резервировал округлённую сумму, а валидатор требовал совпадение с неокруглённой | Изменено. Валидатор принимает применяемый движком расчёт и предыдущее представление. Добавлены тесты для валидных и повреждённых данных |
| P0 | Фактическая операция могла отличаться от Review | При подтверждении использовалась новая рыночная цена | Изменено. Котировка с Review действует до 15 секунд. После обновления цены требуется повторное подтверждение |
| P1 | Кастомный ввод Swap обрезался рядом с закреплённой кнопкой. Вставка суммы в другом десятичном формате не работала | Цифровой блок занимал место в форме, а парсер принимал только разделитель локали | Изменено. Нативный `TextField`, `.decimalPad`, «Готово» и разбор точки и запятой при проверке суммы |
| P1 | Получение средств не генерировало QR-запрос. Сканер возвращал только строку камеры | В операции не существовало сохранённого запроса с получателем, суммой и уникальным ID | Изменено. Локальный формат VELTRIX-TEST, сканирование из Фото, атомарная оплата и запрет повторной оплаты |
| P1 | Основной график показывал пополнение как рост | График отображал абсолютную стоимость без поправки на денежные потоки | Изменено. Графики доходности учитывают внешние потоки. Фиктивные рыночные данные не добавлены |
| P1 | Одинаковые запросы могли запускаться одновременно, а ошибки сервера обрывали обновление сразу | Сетевой слой обрабатывал Retry-After, но не объединял запросы и не повторял временные ошибки | Изменено. Одинаковые запросы объединяются, временные ошибки повторяются с задержками 250 и 500 мс |
| P2 | Главная была малосодержательной после быстрых действий | Страница ограничивалась активами, ссылками и общей суммой | Изменено. Добавлены мини-график, карусель карт, распределение, избранное, популярные монеты, последние операции и настройка порядка |
| P2 | Для карт, лимитов, остатков и конвертера цифровой ввод оставался без явного действия закрытия | У decimalPad нет встроенной кнопки Done | Изменено. Панель нативной клавиатуры с действием «Готово» |
| P3 | Диагностика сети называла котировки CoinGecko даже при активном потоке Kraken | Общий статус использовал дату только REST-ответа | Изменено. Дата берётся из объединённых котировок. Сохранённые данные обозначаются отдельно |

## Проверка

- Исходные скриншоты просмотрены. Они относятся к предыдущей сборке и не показывают изменения этого релиза.
- Локально прошли проверки XML для Info.plist и LaunchScreen.storyboard, цвета #080809, настроек iOS 16 и ARM64, Bundle Identifier, версии 8.1.0, уникальности строк EN/RU и чистоты diff. В Swift-исходниках проверено отсутствие кастомной клавиатуры.
- Добавлены тесты разбора чисел, отмены аутентификации, резерва лимитного ордера, атомарности при сбое сохранения, QR-оплаты, расчёта доходности и нативного ввода. UI-тесты для покупки, продажи, обмена и пополнения переведены на системную клавиатуру.
- Текущая среда Windows не содержит Xcode и iOS Simulator. Доступ к GitHub отсутствует на уровне DNS и соединения. XCTest, новая серия скриншотов и сборка 8.1 здесь недоступны.
- Существенные проверки на устройстве: системный код-пароль и Face ID, быстрое переключение приложений, уведомления и переход по нажатию, камера и фонарик, оба оформления клавиатуры, обновление поверх старой версии с тем же Bundle Identifier и совместимой подписью, плавность на iPhone XS.
- Для ценовых оповещений и лимитных исполнений требуется актуальная котировка во время работы приложения. Для локальной QR-оплаты также требуется актуальная котировка, чтобы зафиксировать стоимость перевода. QR-запросы действуют между портфелями одной локальной базы.
